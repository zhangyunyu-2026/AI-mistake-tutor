# AI错题精灵

## 项目简介
AI错题精灵是一款基于 Python 开发的轻量化智能学习辅助程序，属于人工智能创意应用型项目。本项目模拟 AI 文本生成与交互能力，面向学生错题复盘场景设计，无需依赖大型模型与网络接口，仅使用 Python 内置库即可运行，兼具实用性与趣味性，适合日常学习练习与人工智能入门实践。

## 运行环境
- 开发语言：Python 3.7 及以上版本
- 依赖库：仅使用 Python 内置 `random` 库，无第三方库依赖
- 支持平台：本地 Python 环境、Jupyter Notebook、百度飞桨 AI Studio 等
- 网络要求：纯本地运行，无需联网、无需接口、无需模型加载

## 核心功能说明
1. **错题智能分析**
自动识别题目考察知识点，分析错误原因，并输出标准解题思路，帮助快速定位知识漏洞。

2. **变式题生成**
根据原题考点随机生成同类型练习题，实现举一反三，强化薄弱知识点的巩固。

3. **学习建议推送**
结合错题问题，输出多条可落地的学习指导建议，帮助科学复盘错题、高效提升学习效果。

4. **鼓励文案生成**
随机输出积极暖心的鼓励语句，缓解学习压力，提升程序使用体验。

5. **随机表情包展示**
采用 ASCII 字符制作表情包，随机切换样式并展示在所有内容末尾，增加交互趣味性。

## 使用方法
1. 将项目中的 Python 代码文件下载至本地，在对应 Python 环境中直接运行。
2. 程序内置了测试错题案例，运行后可直接查看全部功能效果。
3. 如需自定义错题内容，可修改代码中的测试样例文本即可。
4. 程序会按顺序依次输出错题分析结果、学习建议、变式练习题、鼓励文案，最后展示随机表情包。

## 其他说明
1. 本项目采用“模板+随机算法”的轻量化方案实现，当前默认支持数学简便运算题型，可自行扩充模板以拓展多学科题型。
2. 所有表情包为纯 ASCII 字符绘制，不占用额外资源，无需图片文件与网络支持。
3. 多次运行程序，文本内容、题目数字、表情包都会随机变化，每次运行效果略有不同。
4. 项目采用模块化代码设计，结构清晰，便于后续维护与二次开发。
